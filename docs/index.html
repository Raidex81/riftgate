Get Riftgate

Free to download. Open the release page, look for Assets, and grab the file for your computer: Riftgate-Setup-…exe for Windows, Riftgate-…-arm64.dmg for a Mac with an Apple chip (M1 or newer), or Riftgate-….dmg for an Intel Mac.

👉 Download the latest version

Windows: a blue "Windows protected your PC" screen may appear the first time — this is normal for independently-published apps that aren't digitally signed yet. Click More info → Run anyway. This only happens once; every update after that installs itself automatically.

Mac: drag Riftgate into Applications, then right-click → Open the first time (or System Settings → Privacy & Security → Open Anyway). If macOS says the app "is damaged", run xattr -cr /Applications/Riftgate.app in Terminal. For now, download each new version by hand on a Mac.

Frequently asked questions

Is Riftgate free?

Yes. Download and use it at no cost.

Do I need to sign in to use it?

No — Riftgate works right away. Signing in is only needed for optional features like Suggestions, and once you've logged in you stay logged in on your device until you choose to log out.

Why does my computer warn me when I install it?

Riftgate is an independently published app and isn't digitally signed, so Windows SmartScreen (or macOS Gatekeeper) shows a caution screen the first time. On Windows click More info → Run anyway; on a Mac, right-click the app → Open. It only happens on the first install.

Will I have to keep reinstalling it?

Not on Windows — after your first install, Riftgate checks for and installs updates automatically. On a Mac, updates can't install themselves until the app is signed, so download the new version from the release page when one comes out (your library and settings are kept).

Is this open source? Can I help?

Yes — Riftgate is open source under the GNU GPL v3.0, and contributions are welcome: bug reports, ideas, fixes and new features. Start with the contributing guide on GitHub.

How do I contact you?

Email the Riftgate team at riftgateappdev@zohomail.eu — questions, suggestions, or an app you'd like listed. Bugs and feature ideas can also go in GitHub issues.
